# Readme
This folder contains the underlying data in my post 4 Key Switch Metrics. As part of my research, I've captured the specs of 435 individual network switches in a (spreadsheet)[https://github.com/GTpyro/knowledge/blob/main/network-switch-analysis/Network%20Switch%20Performance.xlsx] and analyzed it to understand the relationship between the switch buffer size and latency. 

My intermediate analysis is captured in a Jupyter notebook (buffer_size_analysis.ipynb) with the final plot crated in (buffer_size_plot.py), an interactive version of which is hosted as a static page on GitHub.
